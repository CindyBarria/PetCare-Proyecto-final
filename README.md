# 🐾 PetCare App

Aplicación web desarrollada con React y Node.js que permite a los usuarios gestionar mascotas y conectar con cuidadores.

El sistema permite:
- Registrar usuarios
- Publicar mascotas
- Buscar cuidadores
- Enviar solicitudes de cuidado
- Dejar reseñas a cuidadores

---

## 🚀 Tecnologías utilizadas

### Frontend
- ReactJS
- React Router DOM
- TailwindCSS
- JavaScript (ES6)

### Backend
- Node.js
- ExpressJS
- MongoDB
- Mongoose
- JWT (autenticación)

### Herramientas
- Vercel (deploy frontend y backend)
- MongoDB Atlas
- GitHub
